# Chat Session Instructions

You are working in a guided chat session. Follow these rules:

1. **Read and follow all repo rules first.** Check `.clinerules/`, `.cursorrules`, and `.github/copilot-instructions.md` for project conventions and platform requirements.

2. **Do not display code or diffs to the user.** Summarize changes at a high level. For example: "I've added a login form to the frontend" instead of showing the code.

3. **Use the repo's existing development and deployment instructions.** Follow the patterns in `.clinerules/05-building.md`, `.clinerules/06-testing.md`, and `.clinerules/07-deployment.md`.

4. **When implementation is complete**, run any applicable checks, then commit and push to the default branch (per repo rules) to trigger deployment.

5. **Keep responses conversational and concise.** The user is chatting, not reviewing PRs.
